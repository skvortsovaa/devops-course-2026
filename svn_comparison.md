# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN "дорогое"?

В Git ветка представляет собой лёгкий указатель на определённый коммит, поэтому она создаётся быстро и практически не требует дополнительных ресурсов.

В SVN ветвление связано с копированием структуры каталогов внутри централизованного репозитория, поэтому такой подход считается более тяжёлым по сравнению с Git.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN является централизованной системой контроля версий. Для выполнения коммита необходимо подключение к центральному серверу, где хранится репозиторий.

В Git коммиты можно создавать локально без подключения к интернету.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN может использоваться в старых проектах, где уже построена инфраструктура на основе этой системы. Также он может применяться в организациях, где требуется централизованное хранение файлов и строгий контроль доступа.
